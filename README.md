# LIRIK DAN CHORD
**Khusus Lagu Dayak Kalimantan**

Website awal untuk katalog lirik dan chord lagu Dayak Kalimantan.

## Fitur prototipe
- Pencarian judul lagu dan penyanyi/band.
- Daftar penyanyi A–Z yang diurutkan otomatis.
- Kartu lagu contoh untuk halaman populer.
- Halaman detail lirik dan chord contoh.
- Auto-scroll lirik dengan pengaturan kecepatan, jeda, dan lanjutkan.
- Pengaturan ukuran teks dan mode gelap/terang.
- Tampilan responsif untuk HP dan komputer.

> Data lagu saat ini hanya contoh tata letak, bukan lirik atau chord lagu asli. Data dan fitur admin/database akan ditambahkan pada tahap berikutnya.

## Menayangkan website dengan GitHub Pages
1. Buka tab **Settings** pada repositori.
2. Pilih **Pages** di menu samping.
3. Pada **Build and deployment**, pilih **Deploy from a branch**.
4. Pilih branch **main** dan folder **/(root)**, lalu tekan **Save**.
5. Tunggu proses penerbitan selesai, kemudian buka tautan yang muncul pada bagian GitHub Pages.

GitHub Pages menerbitkan file statis seperti `index.html`. Untuk admin online dan penyimpanan data lagu yang dapat diubah tanpa mengedit kode, tahap berikutnya akan membutuhkan database/backend seperti Supabase.

## Teknologi
HTML, CSS, dan JavaScript; GitHub Pages untuk hosting awal.
